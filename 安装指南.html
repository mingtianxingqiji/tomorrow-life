手机端生活记录APP · 安装指南

🚀 最快方式：手机浏览器直接打开

解压后，用手机浏览器访问本地文件即可使用。

通用 方法一：本地运行（推荐）

1将整个 tomorrow-app 文件夹解压到手机或电脑
2确保手机和电脑在同一WiFi网络
3在文件夹目录中打开终端/命令行，运行：
cd tomorrow-app && python3 -m http.server 8080
4查看电脑IP地址，在手机浏览器中访问：
http://你的电脑IP:8080

iOS 添加到主屏幕

1用 Safari 打开 APP 地址
2点击底部中间的 分享按钮（方框↑箭头）
3向下滚动，点击 「添加到主屏幕」
4点击右上角「添加」，桌面就会出现APP图标

💡 添加后就是一个独立APP了，全屏运行，有离线能力！

Android 安装到桌面

1用 Chrome 打开 APP 地址
2浏览器会自动弹出 「安装应用」 横幅
3或点击右上角 ⋮ 菜单 → 「安装应用」/「添加到主屏幕」
4桌面就会出现APP图标，点击即用！

🌐 方法二：部署到公网（随时随地访问）

如果你有服务器或想用免费托管服务：

免费托管选项：

1GitHub Pages：上传到 GitHub 仓库，开启 Pages 功能
2Netlify：拖拽 tomorrow-app 文件夹到 Netlify 即可部署
3Vercel：用 Vercel CLI 一键部署

💡 部署后获得一个 https:// 公网地址，在任何设备上都能打开！然后按上面的方法「添加到主屏幕」。

🔌 运动日记 · 苹果健康数据

在运动日记模块中，点击「连接苹果健康」按钮：

1支持 手动输入 步数、运动时长、卡路里、运动类型
2在 iOS Safari 中添加到主屏幕后，可配合「快捷指令」App 实现自动化健康数据同步

💡 这是PWA的技术限制——浏览器无法直接访问HealthKit。如需深度集成，可将本PWA封装为原生App后接入HealthKit SDK。
